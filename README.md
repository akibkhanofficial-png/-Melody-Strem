# Melody Stream

An independent Android music player project.

**Brand:** Melody Stream  
**Tagline:** Made in India • By Akib Khan

## Current app features
- Home, Search, Library and Profile sections
- Search for songs, artists and albums through the iTunes Search API
- Play available short catalogue previews
- Save and remove favourite tracks locally
- Save a display name and choose between Midnight, Ocean, Sunset and Royal themes
- Mini-player with play/pause and next-preview controls

## Important playback limitation
This build plays only preview URLs returned by the iTunes Search API. It is not a full-length licensed music streaming catalogue. Full-song playback requires a music provider/API whose licence and terms explicitly permit the intended use.

## Build
Open the repository's **Actions** tab and run **Android APK Build**. Download the `melody-stream-debug-apk` artifact from a successful run and extract the APK from the ZIP.
